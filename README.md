# Block homebrew-tap

Homebrew packages for installation of Block open source tools via the [Homebrew package manager](https://docs.brew.sh/).

## Installation

If you don't have Homebrew installed, install that first: https://brew.sh/

Next:

```
brew tap block/tap
brew install <PACKAGE>
```

You can also install a package directly via

```
brew install block/tap/<PACKAGE>
```

Anyone can install these packages, but only Block employees can add new
packages. If you are a Block employee you can see instructions at
[go/block-tap](http://go.sqprod.co/block-tap).
